# PrintCost 3D

Standalone deployment of PrintCost 3D.

[![Deploy with Vercel](https://vercel.com/button)](https://vercel.com/new/clone?repository-url=https%3A%2F%2Fgithub.com%2Fmartintourne9%2FMalten-3D%2Ftree%2Fmain%2Fpublic%2Fprintcost3d&project-name=printcost3d&repository-name=PrintCost-3D)

## Vercel settings

- Project name: `printcost3d`
- Root directory: repository root after the Deploy Button clone
- Framework: Other
- Environment variables: none required for the current beta

## After deploy

Add the final production URL to Supabase Authentication -> URL Configuration -> Redirect URLs so email confirmation and password recovery can return to the standalone app.
