Privacidad

Última actualización: 18 de septiembre de 2026.

PrintCost 3D está en beta. Esta página explica de forma simple qué datos usa la aplicación y para qué.

Datos que guardamos

Cuando creás una cuenta, PrintCost 3D puede guardar tu email, configuraciones de costos, impresoras, materiales, cotizaciones y el feedback que decidas enviar desde la aplicación.

Para qué se usan

Los datos se usan para autenticar tu cuenta, sincronizar tus configuraciones, mostrar tu historial de cotizaciones, aplicar los límites del plan y mejorar el producto durante la beta.

Proveedores técnicos

La aplicación utiliza servicios de infraestructura y autenticación de terceros, actualmente Supabase y Vercel, necesarios para alojar la app, autenticar usuarios y almacenar datos.

Acceso a tus datos

Las reglas de acceso de la aplicación están diseñadas para que cada cuenta vea sus propios datos. No vendemos datos personales ni usamos tus cotizaciones para publicidad de terceros.

Seguridad

Aplicamos controles técnicos como autenticación, permisos por usuario y políticas de acceso en la base de datos. Ningún sistema puede garantizar seguridad absoluta.

Beta y cambios

PrintCost 3D sigue en desarrollo. Esta política puede actualizarse a medida que incorporemos funciones, proveedores o un plan pago. Los cambios relevantes se reflejarán en esta página.

Consultas

Durante la beta podés enviar consultas o reportar problemas desde la opción de feedback disponible dentro de PrintCost 3D.
